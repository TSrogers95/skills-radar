2024/25 funding rules — navigable version

Every section has its own web address, so you can link a colleague straight to the rule rather than sending them a 147-page PDF and a page number.

Read this first: this is a companion, not the document. Each section below summarises what the rule covers and gives the exact paragraph numbers, so you can find it in seconds. It does not reproduce the rule text. That is deliberate — a hand-copied version of a compliance document would drift out of date the moment the Department issued a new version, and you would have no way of knowing. For the wording that actually binds you, open the official PDF, which is linked from every section.
